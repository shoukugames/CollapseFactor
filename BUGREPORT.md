# Reporting a Bug in Collapse Factor

Thank you for helping make Collapse Factor better! Bug reports from players, parents and
teachers are very welcome.

**Email:** info@shoukugames.org
**Website:** https://shoukugames.org/

Please write the subject as: `Collapse Factor bug: <short description>`

---

## Before you report

1. Make sure you are running the latest version. The version number is shown at the
   bottom of the title screen and on the Credits screen.
2. Try restarting the game, because some problems only happen once.
3. If the problem is with a specific level, try **New Layout**. Levels are randomly
   generated, so it helps to know whether the problem happens on every layout or only on one.

## Bug report template

Copy this template into your email and fill in as much as you can:

```
Game version:        (e.g. v0.1.0 - shown on the title screen)
Operating system:    (e.g. Windows 11, Ubuntu 24.04, Debian 12)
Install type:        (.deb package / Windows installer / Windows portable / from source)
Language:            (English / Japanese)
Difficulty:          (Easy / Medium / Hard)
Level number:        (1-20)
Level type:          (River / Lake / Mountain / Tower)

What happened:
  (Describe the problem.)

What you expected to happen:
  (What should the game have done instead?)

Steps to make it happen again:
  1.
  2.
  3.

How often does it happen?  (every time / sometimes / only once)

Screenshot or video:  (attach if possible - very helpful!)
```

## Useful extra information

- **Physics problems** (for example, a structure that should hold collapses, or the other
  way round): please attach a screenshot of your design *before* pressing **Test!**,
  plus the weak-point map from the results screen.
- **Sound problems:** say whether the Music and Sound FX toggles are on, and which audio
  device you use.
- **Graphics problems:** give your screen resolution and whether you use full screen (`F11`).
- **Crashes or a blank window:** on Linux, start the game from a terminal with
  `collapse-factor` and include any text it prints.

## Saved data

Progress and parent statistics are stored locally on the computer:

- **Linux:** `~/.config/Collapse Factor/`
- **Windows:** `%APPDATA%\Collapse Factor\`

You can reset everything from **For Parents → Reset all progress**.

## Privacy

Collapse Factor does not collect or send any data. Nothing leaves your computer unless
you email us a report yourself.

## Security issues

If you find a security problem, please email info@shoukugames.org with the subject
`Collapse Factor security` instead of posting it publicly.
